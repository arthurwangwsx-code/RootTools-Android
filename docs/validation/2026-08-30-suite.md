Background 共用 `RootExecutionPolicy + BoundedProcessRunner`，并在主应用侧串行执行后：

- Root 探针 `exit=0`、`output=0`；
- 首页显示 `ROOT`、`Mi 9T Pro`、实时 CPU/电池值；
- Background 显示“设备控制已就绪 / Root 已授权”；
- 前台稳定 32 秒后主进程 CPU `0.0%`，没有 RootTools `su` / `timeout` / payload orphan；
- 未发现 RootTools 或 Background crash/ANR。

RootTools UID `10270` 的 Magisk 策略 before=`1`（拒绝）、after=`2`（允许），其它字段保持
`until=0 / logging=1 / notification=1`。如需回滚设备授权，仅恢复该 UID 的 `policy=1`。
